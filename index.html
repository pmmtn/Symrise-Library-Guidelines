Ajouter des assets.
Les rendre visibles.

Un guide simple pour passer de la réserve au rayon : on prépare d'abord les contenus dans le back-end, puis on les affiche dans le front-end.

Avant de commencer

Back-end d'abord.
Front-end ensuite.

Le back-end est l'espace d'administration : on y charge les assets, on complète les métadonnées, on crée les filtres et les Libraries. Le front-end est la vitrine visible par les utilisateurs. Tant qu'un asset n'est pas paramétré côté back-end, il ne peut pas apparaître côté front-end.

Administrer
et préparer.

Trois étapes pour charger les contenus, les retrouver proprement, puis créer une Library prête à être utilisée dans le portail.

01

Upload

Charger les nouveaux éléments dans le bon dossier et compléter les informations de base.

  1. 01Aller dans Explore.
  2. 02Sélectionner le dossier cible dans le Media Center.
  3. 03Cliquer sur Upload asset et importer les fichiers.
  4. 04Compléter les métadonnées nécessaires.
  5. 05Ajouter les tags appropriés.
  6. 06Cliquer sur Save and Finish.
+
02

Filtre

Créer une recherche sauvegardée qui isole précisément les bons assets.

  1. 01Cliquer sur Search dans le back-end.
  2. 02Copier/coller le nom exact de l'asset dans la barre de recherche.
  3. 03Vérifier que les bons éléments apparaissent.
  4. 04Icône Save (disquette) → Save as.
  5. 05Nommer le filtre clairement — ex. Care & Wellness pictures.
+
03

Library

Transformer le filtre en collection utilisable dans le portail.

  1. 01Menu gauche → Libraries → New.
  2. 02Renseigner Library name — ex. Care & Wellness.
  3. 03Sélectionner symrise.celum.cloud.
  4. 04Assets → Add a filter → sélectionner le filtre créé.
  5. 05Cliquer sur Create en haut à droite.
+
Front-end · portail visible par les utilisateurs

Publier
et afficher.

Une fois la Library créée côté back-end, elle peut être ajoutée au portail puis affichée sur une page via un widget Asset Gallery.

04

Portail

Ajouter la Library dans le portail pour la rendre disponible côté front-end.

  1. 01Aller dans Experience.
  2. 02Trois petits points → Edit Portal.
  3. 03Onglet Libraries → Add libraries.
  4. 04Sélectionner la Library créée et cliquer sur Save.
+
05

Asset Gallery

Afficher la Library sur une page grâce au widget dédié, puis publier.

  1. 01Aller sur la page à mettre à jour.
  2. 02+ Add section → mise en page une colonne.
  3. 03+ Add widget → sélectionner Asset Gallery.
  4. 04Panneau gauche → Library → sélectionner la bonne Library.
  5. 05Vérifier l'affichage, puis cliquer sur Update.
+
Nommage

Garder une logique cohérente : par exemple Care & Wellness pictures pour le filtre, puis Care & Wellness pour la Library.

Avant publication

Les métadonnées et tags doivent être complétés en amont. Après chaque ajout, toujours vérifier le rendu visible côté front-end.

Si le contenu n'apparaît pas.

L'asset est uploadé dans le bon dossier.
Les métadonnées et tags sont renseignés.
Le filtre contient les bons assets.
La Library est bien reliée au filtre.
La Library est ajoutée dans le portail.
Le widget Asset Gallery utilise la bonne Library.
