Back-end
Administration & configuration
Upload · Filtres · Libraries — 3 étapes
1
Charger les éléments
Upload · métadonnées · tags
›
01Aller dans Explore
02Sélectionner le dossier cible
03Cliquer sur Upload asset et importer les fichiers
04Compléter les métadonnées nécessaires
05Ajouter les tags appropriés
06Cliquer sur Save and Finish
2
Créer un filtre
Recherche · sauvegarde · nommage
›
01Cliquer sur Search dans le back-end
02Coller le nom exact de l'asset dans la barre de recherche
03Vérifier que les bons éléments apparaissent
04Icône Save (disquette) → Save as
05Nommer le filtre — ex. Care & Wellness pictures
3
Créer une Library
Liaison filtre · création
›
01Menu gauche → Libraries → New
02Renseigner Library name — ex. Care & Wellness
03Sélectionner symrise.celum.cloud
04Assets → Add a filter → sélectionner le filtre créé
05Cliquer sur Create en haut à droite
Front-end
Publication & affichage
Portail · Asset Gallery · mise en ligne — 2 étapes
4
Ajouter la Library dans le portail
Experience · Edit Portal · Libraries
›
01Aller dans Experience
02Trois petits points → Edit Portal
03Onglet Libraries → Add libraries
04Sélectionner la Library créée et cliquer sur Save
5
Afficher sur une page
Asset Gallery · section · publication
›
01Aller sur la page à mettre à jour
02+ Add section → mise en page une colonne
03+ Add widget → sélectionner Asset Gallery
04Panneau gauche → Library → sélectionner la Library
05Vérifier l'affichage puis cliquer sur Update
Nommage
Garder une logique cohérente. Ex. Care & Wellness pictures pour le filtre → Care & Wellness pour la Library.
Avant de publier
Métadonnées et tags complétés en amont. Toujours vérifier le rendu front-end après chaque ajout.
