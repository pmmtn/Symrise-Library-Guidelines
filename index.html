Upload Assets

Guide complet pour ajouter et rendre visibles des assets dans la Symrise Library, du chargement dans le back-end à l'affichage sur le front-end.

Back-end vs front-end

Le back-end est l'espace d'administration du DAM : c'est là qu'on charge les assets, complète les métadonnées, crée les filtres et organise les Libraries.

Le front-end est l'interface visible par les utilisateurs : c'est le Media Center où les assets sont consultés, recherchés et téléchargés.

Key principle

Un asset uploadé dans le DAM n'est pas automatiquement visible dans le Media Center.

Il doit être connecté au front-end via une Library, puis affiché sur une page avec une Asset Gallery.

Ajouter un ou plusieurs fichiers dans le bon dossier du DAM.

  • 1Aller dans Explore.
  • 2Sélectionner le dossier dans lequel les assets doivent être chargés.
  • 3Cliquer sur Upload asset et importer les fichiers souhaités.

Qualifier les assets pour garantir leur bon fonctionnement dans les filtres et Libraries.

  • 1Cliquer sur Manage en bas à droite de l'asset.
  • 2Sélectionner Assign asset type.
  • 3Compléter les champs de métadonnées nécessaires.
  • 4Ajouter les tags appropriés pour faciliter la recherche et le filtrage.
Pourquoi c'est important

Des metadata incomplètes ou des tags manquants peuvent empêcher les assets d'apparaître correctement dans les filtres et les Libraries.

Créer un filtre de recherche enregistré, qui permettra d'alimenter automatiquement une Library avec les bons assets.

  • 1Dans le back-end, cliquer sur Search.
  • 2Saisir le nom exact du document ou de l'asset dans la barre de recherche.
  • 3Vérifier que les bons résultats apparaissent.
  • 4Cliquer sur l'icône Save icône disquette.
  • 5Sélectionner Save as.
  • 6Donner un nom clair au filtre. Ex : Care & Wellness pictures
  • 7Enregistrer le filtre.
Convention de nommage

Utiliser un nom descriptif et cohérent avec la future Library. Ex : Care & Wellness pictures pour le filtre → Care & Wellness pour la Library.

Créer une Library liée au filtre créé précédemment, afin de rendre les assets disponibles dans le Media Center.

  • 1Dans le menu de gauche, cliquer sur Libraries.
  • 2Cliquer sur New.
  • 3Renseigner le nom dans le champ Library name. Ex : Care & Wellness
  • 4Sélectionner symrise.celum.cloud.
  • 5Cliquer sur Assets dans le menu de gauche.
  • 6Cliquer sur Add a filter.
  • 7Sélectionner le filtre créé à l'étape précédente.
  • 8Cliquer sur Create en haut à droite.

Rendre la Library disponible dans le portail Media Center, visible des utilisateurs.

  • 1Aller dans Experience.
  • 2Cliquer sur les trois petits points en haut à droite.
  • 3Cliquer sur Edit Portal.
  • 4Aller dans l'onglet Libraries.
  • 5Cliquer sur Add libraries et sélectionner la Library créée.
  • 6Cliquer sur Save.

Ajouter une galerie d'assets sur la page souhaitée du Media Center via un widget Asset Gallery.

  • 1Aller sur la page à mettre à jour.
  • 2Sous le titre, cliquer sur + Add section.
  • 3Dans Choose layout, sélectionner une mise en page en une colonne.
  • 4Cliquer sur + Add widget.
  • 5Sélectionner le widget Asset Gallery.
  • 6Dans le panneau de gauche, aller dans Library et sélectionner la Library créée.
  • 7Vérifier que le contenu apparaît correctement sur la page.
  • 8Cliquer sur Update en bas à gauche.
Vérification

Toujours contrôler l'affichage côté utilisateur après avoir ajouté une nouvelle Library.

Checklist de dépannage

À vérifier si le contenu n'apparaît pas dans le Media Center.

L'asset a bien été uploadé dans le bon dossier.
Les métadonnées et les tags sont bien renseignés.
Le filtre contient bien les bons assets.
La Library est bien reliée au filtre.
La Library a bien été ajoutée dans le portail.
Le widget Asset Gallery utilise la bonne Library.

Bonnes pratiques

Quelques réflexes simples pour garder un Media Center propre et fiable.

Nommage cohérent

Garder une logique entre le filtre et la Library. Ex : Care & Wellness pictures → Care & Wellness.

Tags avant publication

Compléter métadonnées et tags avant de créer le filtre, pour éviter les assets manquants.

Contrôle front-end

Vérifier systématiquement l'affichage côté utilisateur après toute modification.

Une Library par thème

Créer des Libraries ciblées plutôt qu'une seule grande Library globale.
